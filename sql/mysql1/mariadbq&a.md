What command is used to create a database?
CREATE DATABASE database_name;

What command is used to select a database?
USE database_name;

What command is used to display all tables?
SHOW TABLES;

What SQL command is used to add records?
INSERT INTO table_name VALUES (...);

What SQL command is used to retrieve records?
SELECT * FROM table_name;

What is the purpose of PRIMARY KEY?
A PRIMARY KEY uniquely identifies each record in a table. It cannot contain duplicate values.

What is the purpose of AUTO_INCREMENT?
AUTO_INCREMENT automatically generates a new number for a column, usually the PRIMARY KEY, whenever a new record is added.

What is the difference between UPDATE and DELETE?
UPDATE is used to modify existing records in a table. DELETE is used to remove records from a table.
